# youzhiyouxing-bookkeeping

一个 Claude 技能（Skill），用来在 [有知有行](https://yx.youzhiyouxing.cn)（yx.youzhiyouxing.cn）里完成**月度记账**：把各个账户的截图整理成资产盘点、投资记账和现金流记录，并在录入后读回核对。

> 本仓库是**脱敏的通用模板**，不含任何真实的账户、机构名称、账户 ID、卡号尾号、授信额度或金额。真实映射由使用者在调用时提供，或保存在自己的私有技能 / 本地文件中，**不要提交回本仓库**。

## 它能做什么

- **资产盘点**（`/balance/inventory`）：按分类（流动资金、负债等）更新各账户的金额、日期和备注，核对分类合计与家庭总览。
- **投资记账**（`/abooks`）：录入人民币、港币投资账户的「投入 / 转出」和「当天资产金额」，保证同一天内流水在前、资产快照在后。
- **现金流口径**：区分基金子账户、基金平台、含现金的证券账户各自哪些资金进出算外部现金流，避免重复记或漏记。
- **核验与交付**：每笔提交前检查日期、类型、渠道、金额，提交后读回历史记录；最终列出已写入项、待核实项和有疑点的口径。

## 适用与不适用

适用：根据截图和余额，做每月一次的资产、负债和投资账户盘点；补记遗漏的流水。

不适用：投资交易本身，以及日常消费流水账。

## 怎么用

1. 把 `SKILL.md` 放进 Claude 的技能目录，或在支持技能的客户端里作为自定义技能导入。
2. 准备好**私有配置**（见 `SKILL.md` 末尾「私有配置格式」）：
   - 渠道与账户映射：每个占位（`<渠道A>`、`<信用卡1>` 等）对应的真实名称、位置、截图取哪个数字、是否必须有流水；
   - 数值与 ID：投资账户 ID、资产盘点账户的 `cid`、信用卡尾号、授信额度、沿用金额；
   - 写法约定与个人规则：例如哪些渠道出入金频繁、哪些账户已注销、哪些项目需要沿用账本值。
3. 在已登录有知有行的浏览器里，对 Claude 说「记账」并附上各账户截图。缺什么信息，Claude 会用选择题一次问清。

建议把填好真实值的完整版另存为**私有技能**，日常直接调用；公开模板只用来分享流程和口径。

## 几条重要约定

- **日期**：月度快照默认记当月 1 日，并包含上月全月流水。站点不接受未来日期，月末不要抢记次月 1 日。
- **不可逆操作**：助手不执行永久删除。需要删除时，由助手打开页面并定位到那一行，用户自己点删除。
- **先流水、后快照**：投资记账同日最终顺序必须是投入/转出在前、资产快照在后，否则顶部总额会临时偏离真实市值。
- **缺失的流水**：出入金频繁的渠道必须有流水依据，没提供就先问；出入金很少的渠道，没提供即视为没有。具体划分以私有配置为准。
- **不从资产差额倒推投入**，也不把累计收益当作本月收益。
