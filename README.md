# youzhiyouxing-bookkeeping

上传账户截图，让 Claude 在**有知有行网页端**（[yx.youzhiyouxing.cn](https://yx.youzhiyouxing.cn)）自动完成月度记账的 Claude 技能。

> 本仓库是**脱敏的通用模板**，不含真实账户、机构名、ID、卡号尾号、额度或金额。真实信息由使用者在调用时提供，不要提交回本仓库。

## 它解决什么问题

每月给银行、基金平台、券商、信用卡逐个翻页面、抄数字、填表，既费时又容易填错。这个技能把流程交给 Claude：你把各账户的截图发过来，Claude 在已登录的网页里把数据录进去，再读回核对。

## 工作方式

- **只在网页端**：Claude 通过浏览器操作有知有行的 Web 页面，不是 App，也不走接口。需要一个已登录有知有行的浏览器。作者用的是 Claude 桌面应用的内置浏览器。
- **你提供截图，Claude 录入**：资产盘点（现金、负债）和投资记账（人民币、港币账户的资产金额、投入、转出）都由 Claude 填写并保存。
- **录完会核对**：提交前检查日期、类型、渠道、金额，提交后读回历史记录和家庭总览。最后给你一份清单：已写入的、待核实的、口径有疑点的。
- **缺信息会问**：缺少流水或归属不明时，用选择题一次问清，不会默认当作零。

## 作者的使用习惯（决定了规则怎么设计）

这套规则是围绕**每月只记一次账**设计的，不一定适合你：

- 每月 1 日盘点一次，快照记在当月 1 日，并把上个月全月的资金进出汇总进同一天，不逐笔、不每天记。
- 因此现金流只看「月度汇总」：基金页的近一月交易汇总、银行侧的扣款记录，而不是每一笔明细。
- 出入金频繁的渠道（基金平台、基金子账户）必须有流水依据；出入金很少的渠道（券商），没提供就视为没有。
- 站点不接受未来日期，所以月末不提前记次月 1 日，等到 1 日再录。

如果你习惯每天或每周记，这里的日期规则、汇总口径和「没提供就是没有」的约定都需要改。

## 使用步骤

1. 把 `SKILL.md` 导入 Claude 的技能（或放进技能目录）。
2. 准备**私有配置**（格式见 `SKILL.md` 末尾）：各渠道的真实名称与截图取数口径、投资账户 ID、资产盘点账户 `cid`、信用卡尾号和额度、个人规则。建议存成自己的私有技能，日常直接调用。
3. 登录有知有行网页，对 Claude 说「记账」，附上各账户截图。

## 局限

- 登录要你自己完成（验证码），Claude 不代填。
- **Claude 不执行永久删除**。资产盘点的历史记录没有编辑入口，录错日期只能删除重来，需要你自己点垃圾桶；所以规则里尽量一次录对。
- 页面操作经验来自 2026-11 的网页版本，改版后以实际页面为准。
- 截图里的数字由 Claude 识别，小数位可能出错，录入后会读回核对，但最终金额仍建议你扫一眼。
- 本仓库内容不构成投资或财务建议。
